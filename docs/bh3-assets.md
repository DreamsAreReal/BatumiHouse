# Batumi House 3 assets

- Property imagery is the existing catalogue's imagery, without replacement or
  deletion. Orbi C base64 gallery entries are decoded losslessly at build time
  into separate WebP files; the original gallery JSON remains intact.
- The old 480px hero remains in the repository. The new panorama is a real
  photograph of Batumi by Max (@baseddesigner), published 6 July 2021:
  https://unsplash.com/photos/RCYC9Fa_wb0
  Source identifies free use under https://unsplash.com/license . Downloaded
  from its primary images.unsplash.com URL and optimized to 2400x1600 WebP.
- The reference is a composed mockup; its apartment prices, furnished interiors,
  agent portrait, rating/verification claims and sales offers are not data.
  They are not imported as actual property information.
- UI icons are unmodified Tabler Icons 3.50.0 SVG assets (MIT), with the bundled
  license at images/ui3/LICENSE. CSS masks apply the approved palette.
- Existing illustrative listing imagery remains explicitly labelled as an
  illustration. No generated photograph is presented as a real listing photo.
